# Existing Mnema typeface

These unmodified Inter Latin normal 400, 500 and 600 WOFF2 files come from
the repository's existing `@fontsource/inter` version 5.3.0 dependency in
`web/node_modules/@fontsource/inter/files/`. The web app loads that same
typeface in `web/src/main.ts`. The developer probe bundles these files locally;
it makes no third-party font requests.

Inter is licensed under the SIL Open Font License 1.1. The unchanged upstream
license is included as `Inter-LICENSE.txt`. Upstream package:
https://github.com/fontsource/font-files/tree/main/fonts/google/inter.
